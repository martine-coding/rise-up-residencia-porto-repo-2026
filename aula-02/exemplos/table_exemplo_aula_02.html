💻 Estrutura HTML da tabela

<!-- Tabela com cabeçalho e corpo -->
<table>
  <thead>
    <tr>
      <th>Nome</th>
      <th>Idade</th>
      <th>Cidade</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ana</td>
      <td>25</td>
      <td>Recife</td>
    </tr>
    <!-- mais linhas... -->
  </tbody>
</table>

🏷️ Tags da Tabela

Tag Função Exemplo de uso
<table> Container da tabela <table class="tabela">
<thead> Cabeçalho da tabela (títulos) <thead><tr><th>Nome</th></tr></thead>
<tbody> Corpo da tabela (dados) <tbody><tr><td>Ana</td></tr></tbody>
<tr> Linha da tabela <tr>...</tr>
<th> Célula de cabeçalho (negrito, centralizado) <th>Nome</th>
<td> Célula de dados <td>Ana</td>
<tfoot> Rodapé da tabela (totais, resumos) <tfoot><td>Total: 10</td></tfoot>

📐 Organização da Tabela

📌 <thead> — Cabeçalho

Agrupa as linhas de título da tabela.

<thead>
  <tr>
    <th>Nome</th>
    <th>Idade</th>
  </tr>
</thead>

→ Negrito e centralizado automaticamente

📌 <tbody> — Corpo

Agrupa as linhas de dados da tabela.

<tbody>
  <tr>
    <td>Ana</td>
    <td>25</td>
  </tr>
  <tr>
    <td>João</td>
    <td>30</td>
  </tr>
</tbody>

→ Dados organizados em linhas e colunas

💡 Por que usar <thead> e <tbody>?
• Facilita a estilização (cabeçalho com fundo escuro, linhas alternadas)
• Torna o código mais semântico e acessível
• Permite rolagem independente do corpo em tabelas grandes
• Melhora a manutenção do código

⚙️ Atributos Importantes

Atributo Função Exemplo
colspan Mescla colunas horizontalmente colspan="2" — ocupa 2 colunas
rowspan Mescla linhas verticalmente rowspan="3" — ocupa 3 linhas
scope Define se é cabeçalho de coluna ou linha (acessibilidade) scope="col" ou scope="row"
border Define a borda da tabela (depreciado, usar CSS) border="1"

🔗 colspan

<td colspan="3">Mensagem</td>

Ocupa 3 colunas de uma vez

🔗 rowspan

<td rowspan="2">Dados</td>

Ocupa 2 linhas de uma vez

📌 Resumo das Tabelas

Tags principais:
  • • <table> → container da tabela
  • • <thead> → cabeçalho (títulos)
  • • <tbody> → corpo (dados)
  • • <tr> → linha
  • • <th> → célula de cabeçalho
  • • <td> → célula de dados
Atributos importantes:
  • • colspan → mescla colunas
  • • rowspan → mescla linhas
  • • scope → acessibilidade

Organização:
  • • <thead> → títulos
  • • <tbody> → dados
