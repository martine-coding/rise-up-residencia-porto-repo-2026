✨ Pseudo-classes: Estilos Dinâmicos

"Pseudo-classes dão vida ao CSS sem precisar de JavaScript."

🎯 Estados do Elemento :hover · :focus · :active

:hover
Muda cor e escala ao passar o mouse
:focus
Borda azul ao selecionar o campo
:active
Encolhe e escurece ao clicar
.botao:hover {
  background: #2b6cb0;
  transform: scale(1.05);
}

input:focus {
  border-color: #667eea;
  box-shadow: 0 0 0 4px rgba(102,126,234,0.2);
}

}

📌 Resumo das Pseudo-classes

Estados do elemento:
  • • :hover → mouse sobre o elemento
  • • :focus → elemento selecionado
  • • :active → elemento sendo clicado
Posição na estrutura:
  • • :first-child → primeiro filho
  • • :last-child → último filho
  • • :nth-child(n) → enésimo filho
