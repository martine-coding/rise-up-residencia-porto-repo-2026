📝 Formulários: Capturando Informações

"Formulários são a ponte entre o usuário e o sistema."

📋 Exemplo Prático Formulário de Contato

💻 Estrutura HTML do formulário

<!-- Estrutura básica do formulário -->
<form action="/enviar" method="POST">

  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome" placeholder="Digite seu nome" required>

  <label for="email">E-mail:</label>
  <input type="email" id="email" name="email" placeholder="email@exemplo.com">

  <label for="mensagem">Mensagem:</label>
  <textarea id="mensagem" name="mensagem" rows="4"></textarea>

  <button type="submit">Enviar</button>
</form>

🏷️ Tags Importantes

Tag Função
<form> Container do formulário
<label> Rótulo descritivo para o campo
<input> Campo de entrada de dados
<textarea> Área de texto (mensagens maiores)
<button> Botão para enviar ou cancelar
<select> Menu de opções (dropdown)
<option> Opção dentro do select

⚙️ Atributos Importantes

Atributo Função Exemplo
type Define o tipo do input type="text", type="email", type="password"
id Identifica o campo (ligado ao label) id="nome"
name Nome do campo (importante para envio) name="nome"
placeholder Texto de exemplo dentro do campo placeholder="Digite seu nome"
required Campo obrigatório required
value Valor padrão do campo value="João"
rows Número de linhas (textarea) rows="4"
⚠️ Atenção: O atributo for no <label> deve ser igual ao id no <input>.
Isso é essencial para acessibilidade e para que o clique no label selecione o campo.

☑️ Checkbox e Radio

📌 Checkbox (múltipla escolha)

🔘 Radio (escolha única)

<!-- Checkbox (múltipla escolha) -->
<input type="checkbox" name="interesses" value="css"> CSS

<!-- Radio (escolha única) -->
<input type="radio" name="genero" value="masculino"> Masculino

📤 O que acontece ao enviar?

📦 Dados enviados

nome=João+Silva
email=joao@email.com
mensagem=Olá%2C+estou+entrando+em+contato...

Os dados são enviados via method="POST" ou method="GET"

⚙️ Atributos do <form>

action = "/enviar"
method = "POST"
POST: dados no corpo da requisição
GET: dados na URL (query string)

📌 Resumo dos Formulários

Tags principais:
  • • <form> → container do formulário
  • • <label> → rótulo descritivo
  • • <input> → campo de entrada
  • • <textarea> → área de texto
  • • <button> → botão de ação
Atributos importantes:
  • • type → text, email, password, etc
  • • id → ligado ao label (for)
  • • name → identificador para envio
  • • placeholder → texto de exemplo
  • • required → campo obrigatório
