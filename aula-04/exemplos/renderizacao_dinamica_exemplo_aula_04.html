🔄 Renderizando Dados Dinamicamente

"Em vez de escrever cada linha da tabela no HTML, usamos JS para gerar o conteúdo a partir de listas de dados."

💡 Por que renderizar dinamicamente?

Imagina que você tem 50 usuários para exibir. Escrever 50 blocos HTML à mão seria inviável e impossível de manter. Com JavaScript, escrevemos um template e ele gera todos os cards automaticamente a partir de um array de objetos.

📋

Sem Renderização Dinâmica

Você escreve manualmente cada card no HTML. Se mudar de 3 para 50 usuários, reescreve tudo.

⚡

Com Renderização Dinâmica

Você escreve um template uma vez. O JS percorre o array e gera todos os cards automaticamente.

📦 Passo 1 — Criar o Array de Objetos

Começamos com uma lista de dados. Cada item é um objeto com as propriedades que queremos exibir.

const listaUsuarios = [
  { nome: "Ana Silva", status: "Ativo" },
  { nome: "Carlos Souza", status: "Pendente" },
  { nome: "Beatriz Lima", status: "Ativo" },
  { nome: "Pedro Costa", status: "Inativo" }
];
💡 Lembre-se: Um array de objetos é uma lista onde cada item tem chave e valor. É a estrutura mais comum para representar dados no frontend.

🎯 Passo 2 — Selecionar o Container

Precisamos de um elemento HTML onde os cards serão inseridos. Geralmente uma <div> vazia com um ID.

<!-- HTML -->
<div id="lista-container"></div>

// JavaScript
const container = document.querySelector("#lista-container");
💡 Dica: Use #id para selecionar por ID no querySelector. É a mesma sintaxe do CSS.

⚡ Passo 3 — Gerar o HTML Dinamicamente

Usamos forEach para percorrer o array e innerHTML para inserir o HTML gerado. Usamos template strings (com crase) para interpolar os dados.

listaUsuarios.forEach((user) => {
  container.innerHTML += `
    <div class="user-card">
      <p>${user.nome} - <span>${user.status}</span></p>
    </div>
  `;
});
⚠️ Atenção ao +=
Usamos innerHTML += para adicionar ao conteúdo existente. Se usar apenas =, você substitui tudo a cada iteração — e só o último item aparece!

🎮 Demonstração ao Vivo

Os cards abaixo foram gerados automaticamente pelo JavaScript a partir de um array de objetos. Clique nos botões para ver a renderização em ação.

👥 Lista de Usuários

// Função que renderiza os usuários
function renderizarUsuarios() {
  const container = document.querySelector("#lista-container");
  container.innerHTML = ""; // Limpa antes de renderizar

  listaUsuarios.forEach((user) => {
    const classeStatus = user.status.toLowerCase();
    container.innerHTML += `
      <div class="user-card">
        <div class="nome">${user.nome}</div>
        <span class="status status-${classeStatus}">${user.status}</span>
      </div>
    `;
  });
}

📊 Bônus — Tabela Renderizada Dinamicamente

O mesmo conceito se aplica a tabelas. Em vez de escrever cada linha, percorremos o array e geramos as linhas.

📋 Tabela de Usuários

# Nome Status
const tbody = document.querySelector("#tabela-body");

listaUsuarios.forEach((user, index) => {
  tbody.innerHTML += `
    <tr>
      <td>${index + 1}</td>
      <td>${user.nome}</td>
      <td>${user.status}</td>
    </tr>
  `;
});

✍️ Exercício Prático

📝 Mão na massa:

  1. Crie um array de objetos chamado listaCursos com:
    • 3 cursos
    • Cada curso com nome e cargaHoraria
  2. No HTML, crie uma <div id="cursos-container">
  3. No script.js, selecione o container com querySelector
  4. Use forEach para percorrer o array e gerar um card para cada curso
  5. Cada card deve mostrar o nome e a carga horária

📌 Resumo da Renderização Dinâmica

Os 3 passos:
  • • 1️⃣ Criar o array de objetos
  • • 2️⃣ Selecionar o container
  • • 3️⃣ Percorrer com forEach e gerar o HTML
Ferramentas usadas:
  • • querySelector → selecionar
  • • forEach → percorrer
  • • innerHTML += → inserir
  • • ${} → interpolar dados
