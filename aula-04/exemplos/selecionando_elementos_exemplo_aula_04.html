🔍 Selecionando Elementos HTML

"Para alterar algo na tela, o JS precisa primeiro encontrar o elemento correto."

🎯 Por que Selecionar? O primeiro passo da manipulação

O JavaScript não consegue alterar um elemento se não souber qual elemento é. Por isso, o primeiro passo de qualquer manipulação do DOM é selecionar o elemento.

// ❌ Errado — não dá pra alterar sem selecionar
// "muda o título" — mas qual título?

// ✅ Certo — primeiro seleciona, depois altera
const titulo = document.getElementById("titulo-dashboard");
titulo.textContent = "Novo título!";
💡 Regra de ouro: Selecionar → Manipular. Sempre nessa ordem.

🛠️ Os 4 Métodos Principais

getElementById

Por ID

Seleciona 1 elemento pelo atributo id.

Retorna: 1 elemento
Ex: getElementById("titulo")
querySelector

Por Seletor CSS

Seleciona o primeiro elemento que bate com o seletor.

Retorna: 1 elemento
Ex: querySelector(".card")
querySelectorAll

Todos por Seletor

Seleciona todos os elementos que batem com o seletor.

Retorna: NodeList
Ex: querySelectorAll(".btn")
getElementsByClassName

Por Classe

Seleciona todos os elementos com determinada classe.

Retorna: HTMLCollection
Ex: getElementsByClassName("item")

💻 Exemplos Práticos

1. Selecionar por ID

const titulo = document.getElementById("titulo-dashboard");

2. Selecionar por seletor CSS (mais comum)

const card = document.querySelector(".card-metrica");
const todosOsBotoes = document.querySelectorAll(".btn-acao");

3. Manipulando o que foi selecionado

// Alterando o texto do título
titulo.textContent = "Dashboard Atualizado";

// Percorrendo todos os botões
todosOsBotoes.forEach((botao) => {
  botao.style.background = "#48bb78";
});

// Selecionar o título por ID
function selecionarTitulo() {
  const titulo = document.getElementById("titulo-dashboard");
  titulo.textContent = "✨ Título selecionado por ID!";
  titulo.style.color = "#667eea";
}

// Selecionar todos os cards por classe
function selecionarCards() {
  const cards = document.querySelectorAll(".card-metrica");
  cards.forEach((card) => {
    card.style.background = "linear-gradient(135deg, #48bb78, #38a169)";
  });
}

🤔 Quando usar cada método?

Situação Método ideal
Preciso alterar um elemento único (ex: um título) getElementById
Preciso do primeiro elemento que bate com um seletor CSS querySelector
Preciso de todos os elementos de uma classe querySelectorAll
Quero usar seletores CSS complexos (ex: .card > p) querySelector / querySelectorAll
Quero percorrer vários elementos com forEach querySelectorAll
💡 Dica prática: Na dúvida, use querySelector e querySelectorAll. Eles aceitam qualquer seletor CSS, o que dá muito mais flexibilidade.

✍️ Exercício Prático

📝 Mão na massa:

  1. Crie um HTML com:
    • Um <h1 id="titulo">
    • Três <div class="card">
    • Dois <button class="btn">
  2. No script.js, selecione o h1 com getElementById
  3. Selecione os cards com querySelectorAll(".card")
  4. Selecione os botões com querySelectorAll(".btn")
  5. Use forEach para percorrer os cards e alterar o texto

📌 Resumo da Seleção

Métodos:
  • • getElementById → 1 elemento por ID
  • • querySelector → 1 elemento por seletor
  • • querySelectorAll → todos por seletor
  • • getElementsByClassName → todos por classe
Ordem de uso:
  • • 1️⃣ Selecionar o elemento
  • • 2️⃣ Manipular (texto, estilo, classe)
  • • 3️⃣ Reagir a eventos

Regra de ouro:

Sempre selecionar antes de manipular.
