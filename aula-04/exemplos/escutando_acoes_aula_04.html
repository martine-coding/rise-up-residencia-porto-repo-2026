👂 Escutando Ações do Usuário

"O método addEventListener fica ouvindo as interações da página para disparar funções de resposta."

🎧 O que é Escutar Eventos?

Até agora, nós selecionamos e manipulamos elementos. Mas como fazer a página reagir quando o usuário clica, digita ou passa o mouse? A resposta é: escutando eventos.

🔍

Selecionar

Primeiro encontramos o elemento que vai disparar o evento.

👂

Escutar

Usamos addEventListener para "ficar ouvindo" aquele elemento.

⚡

Reagir

Quando o evento acontece, uma função é executada automaticamente.

💡 Analogia: É como uma campainha. Você instala a campainha (seleciona + escuta), e quando alguém aperta (evento), ela toca (executa a função).

📝 Sintaxe do addEventListener

elemento.addEventListener("evento", function(event) {
  // o que fazer quando o evento acontecer
});

O método recebe dois argumentos:

Argumento O que é Exemplo
1º Tipo do evento (string) "click", "submit", "input"
2º Função de resposta function() { ... }

🎯 Eventos Mais Comuns

Evento Quando dispara
click Quando o usuário clica em um elemento
submit Quando um formulário é enviado
input A cada caractere digitado em um campo
change Quando o valor de um campo muda
mouseover Quando o mouse passa sobre um elemento
keydown Quando uma tecla é pressionada

💻 Exemplo Completo

const botaoEnviar = document.querySelector("#btn-salvar");

botaoEnviar.addEventListener("click", function(event) {
  event.preventDefault(); // Impede o recarregamento da página
  console.log("running"); // Feedback de execução
});
💡 O que é event.preventDefault()?
Por padrão, um formulário recarrega a página ao ser enviado. O preventDefault() cancela esse comportamento, permitindo que a gente controle o que acontece via JavaScript.

🎮 Demo 1 — Evento de Clique

Clique no botão abaixo. O evento click está sendo escutado e cada clique gera uma linha no console visual.

🔘 Testando o evento de clique

Console vazio... clique no botão acima.
const botao = document.querySelector("#btn-click");
const console1 = document.querySelector("#console-1");

botao.addEventListener("click", function() {
  console1.innerHTML += `<div class="linha"><span class="prompt">></span><span class="output">Botão clicado!</span></div>`;
});

🎮 Demo 2 — Evento de Submit + preventDefault

Preencha o formulário e clique em "Salvar". O evento submit é escutado e o preventDefault() impede que a página recarregue.

📝 Formulário de Cadastro

Console vazio... preencha o formulário e clique em Salvar.
const formulario = document.querySelector("#form-demo");
const console2 = document.querySelector("#console-2");

formulario.addEventListener("submit", function(event) {
  event.preventDefault(); // Impede o recarregamento da página

  const nome = document.querySelector("#nome-input").value;
  const email = document.querySelector("#email-input").value;

  console.log("running");
  console2.innerHTML += `<div class="linha"><span class="prompt">></span><span class="output">Nome: ${nome} | Email: ${email}</span></div>`;
});
💡 Lembre-se: Sempre use event.preventDefault() no evento de submit quando quiser controlar o comportamento do formulário com JavaScript.

🎮 Demo 3 — Evento de Input (Tempo Real)

Digite algo no campo abaixo. O evento input é disparado a cada caractere digitado.

⌨️ Escutando cada caractere

Você digitou:
(nada ainda)
Total de caracteres:
0
const input = document.querySelector("#input-tempo-real");
const resultado = document.querySelector("#resultado-input");
const tamanho = document.querySelector("#resultado-tamanho");

input.addEventListener("input", function() {
  resultado.textContent = input.value || "(nada ainda)";
  tamanho.textContent = input.value.length;
});

✍️ Exercício Prático

📝 Mão na massa:

  1. Crie um HTML com:
    • Um <input id="nome">
    • Um <button id="btn">
    • Um <p id="resultado">
  2. No script.js, selecione os três elementos
  3. Adicione um addEventListener("click") no botão
  4. Ao clicar, pegue o valor do input e exiba no <p>
  5. Bônus: adicione um addEventListener("input") no input para mostrar em tempo real

📌 Resumo dos Eventos

Sintaxe:
  • • addEventListener → escuta eventos
  • • 1º argumento → tipo do evento
  • • 2º argumento → função de resposta
Eventos comuns:
  • • click → clique
  • • submit → envio de formulário
  • • input → digitação
  • • change → mudança de valor
💡 Dica de ouro: Use event.preventDefault() no submit para evitar o recarregamento da página.
