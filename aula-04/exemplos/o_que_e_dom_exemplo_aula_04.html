🌳 O que é o DOM?

"A partir do DOM é que vamos dar vida à página."

🧠 Três Conceitos Fundamentais

🌳

A Árvore da Página

O DOM é a representação em árvore do seu documento HTML dentro da memória do navegador.

🌉

Ponte de Conexão

Permite que o JavaScript leia, altere, adicione ou remova elementos HTML e estilos CSS em tempo real.

⚡

Do Estático ao Vivo

Sem o DOM, o HTML seria apenas um documento fixo, sem capacidade de resposta às ações do usuário.

🌳 A Árvore do DOM Representação visual

Quando o navegador carrega um HTML, ele cria uma árvore de objetos na memória. Cada tag se torna um nó (node) dessa árvore.

document
└── <html>
├── <head>
│ ├── <meta>
│ └── <title>
│ └── "Minha Página"
└── <body>
├── <header>
│ └── <h1>
│ └── "Olá, mundo!"
└── <p>
    └── "Bem-vindo"

🔍 Como Acessar o DOM Seletores do JavaScript

Para manipular o DOM, primeiro precisamos selecionar os elementos. Existem várias formas:

Método O que faz Exemplo
getElementById() Seleciona por ID document.getElementById("alvo")
querySelector() Seleciona o primeiro elemento (CSS selector) document.querySelector(".classe")
querySelectorAll() Seleciona todos os elementos document.querySelectorAll("p")
getElementsByClassName() Seleciona por classe document.getElementsByClassName("item")
// Selecionando um elemento pelo ID
let titulo = document.getElementById("alvo");

// Selecionando pelo seletor CSS
let paragrafo = document.querySelector("p");

// Selecionando todos os parágrafos
let todos = document.querySelectorAll("p");

✏️ Manipulando o DOM Lendo, alterando e criando

Ação Propriedade / Método Exemplo
Ler texto textContent el.textContent
Alterar texto textContent el.textContent = "Novo"
Alterar HTML innerHTML el.innerHTML = "<b>Oi</b>"
Alterar estilo style el.style.color = "red"
Adicionar classe classList.add() el.classList.add("ativo")
Remover classe classList.remove() el.classList.remove("ativo")
Criar elemento createElement() document.createElement("p")
Adicionar ao DOM appendChild() pai.appendChild(filho)

🎮 Demonstração ao Vivo Clique nos botões

Este é um exemplo real de manipulação do DOM. Os botões abaixo alteram o elemento com ID alvo.

🎯 Eu sou o alvo!
// Mudar o texto do elemento
function mudarTexto() {
  let el = document.getElementById("alvo");
  el.textContent = "✨ Texto alterado pelo JavaScript!";
}

// Mudar a cor do texto
function mudarCor() {
  let el = document.getElementById("alvo");
  el.style.color = "#E83F6F";
}

// Mudar a cor de fundo
function mudarFundo() {
  let el = document.getElementById("alvo");
  el.style.background = "#FEF3C7";
}

// Resetar tudo
function resetar() {
  let el = document.getElementById("alvo");
  el.textContent = "🎯 Eu sou o alvo!";
  el.style.color = "#667eea";
  el.style.background = "#f7fafc";
}

⚡ Do Estático ao Vivo Por que o DOM importa?

📄

Sem DOM

HTML é só um documento fixo. Não reage a cliques, não muda textos, não cria elementos.

⚡

Com DOM

A página se torna viva. Reage a ações, atualiza conteúdos, cria e remove elementos dinamicamente.

💡 Lembre-se: O DOM é a ponte entre o HTML e o JavaScript. Sem ele, não há interatividade, não há resposta ao usuário, não há vida.

✍️ Exercício Prático

📝 Mão na massa:

  1. Crie um HTML com um <h1 id="titulo"> e um <button>
  2. No script.js, selecione o título com getElementById
  3. Adicione um evento de clique no botão
  4. Ao clicar, altere o texto do título com textContent
  5. Bônus: altere também a cor do título com style.color

📌 Resumo do DOM

O que é:
  • • Representação em árvore do HTML
  • • Ponte entre HTML e JavaScript
  • • Permite leitura e manipulação em tempo real
Como usar:
  • • getElementById → seleciona por ID
  • • querySelector → seletor CSS
  • • textContent → ler/alterar texto
  • • style → alterar CSS
  • • classList → adicionar/remover classes
