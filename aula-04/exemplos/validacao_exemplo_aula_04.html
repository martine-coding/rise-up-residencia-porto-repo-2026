✅ Validação de Dados em Tempo Real

"Dá resposta imediata antes do envio — e evita dados incorretos ou vazios."

🎯 Por que Validar no JS?

🚫

Evita dados incorretos

Impede que o usuário envie informações vazias, inválidas ou mal formatadas.

✨

Melhora a UX

Alertas claros e imediatos evitam frustração e ajudam o usuário a corrigir erros.

⚡

Resposta imediata

O usuário sabe na hora se está preenchendo certo, sem esperar o envio.

💡 Regra de ouro: Validar antes do envio é mais barato que corrigir depois. O usuário agradece pela clareza.

💻 Exemplo Prático — Validação no Submit

Validamos um campo de e-mail antes de permitir o envio do formulário. Se estiver vazio, exibimos um alerta. Se estiver preenchido, seguimos em frente.

const emailInput = document.querySelector("#email");

if (emailInput.value === "") {
  alert("Por favor, preencha o e-mail!");
} else {
  console.log("functional");
}
⚠️ Atenção: Um alert() é o jeito mais simples de dar feedback, mas não é a melhor experiência. Mais à frente, vamos usar mensagens visuais direto no formulário.

📋 Tipos Comuns de Validação

Tipo Como validar Exemplo
Campo vazio Verificar se o valor é "" if (input.value === "")
Tamanho mínimo Verificar o .length if (input.value.length < 3)
Formato de e-mail Usar expressão regular (regex) /^[^@]+@[^@]+\.[^@]+$/
Apenas números Verificar se é numérico if (!isNaN(input.value))
Idade mínima Comparar valores numéricos if (idade < 18)

⚡ Validação em Tempo Real Enquanto o usuário digita

Em vez de validar só no submit, podemos validar a cada caractere digitado usando o evento input. Assim, o usuário vê o feedback na hora.

const emailInput = document.querySelector("#email");
const campo = emailInput.closest(".campo");

emailInput.addEventListener("input", function() {
  const valor = emailInput.value.trim();

  // Remove estados anteriores
  campo.classList.remove("valido", "invalido");

  // Se estiver vazio, não mostra nada ainda
  if (valor === "") return;

  // Se não tiver @ ou ., está inválido
  if (!valor.includes("@") || !valor.includes(".")) {
    campo.classList.add("invalido");
  } else {
    campo.classList.add("valido");
  }
});
💡 Por que isso é bom?
• Feedback imediato — o usuário sabe na hora se está certo.
• Sem esperar o envio — menos frustração.
• Mais acessível — a validação visual ajuda a todos.

// Função para validar cada campo
function validarCampo(input, campo, condicao) {
  const valor = input.value.trim();
  campo.classList.remove("valido", "invalido");

  if (valor === "") return;

  if (condicao(valor)) {
    campo.classList.add("valido");
  } else {
    campo.classList.add("invalido");
  }
}
💡 Boa prática: Criar uma função reutilizável para validar qualquer campo. Assim, você não repete código para cada input.

✍️ Exercício Prático

📝 Mão na massa:

  1. Crie um formulário com:
    • <input id="nome">
    • <input id="email">
    • <button type="submit">
  2. Selecione os campos com querySelector
  3. Adicione um addEventListener("input") em cada campo
  4. Valide:
    • Nome → pelo menos 3 caracteres
    • E-mail → contém @ e .
  5. Adicione uma classe .valido ou .invalido ao campo
  6. Use CSS para colorir a borda de verde ou vermelho

📌 Resumo da Validação

Por que validar:
  • • Evita envio de dados incorretos
  • • Melhora a experiência do usuário
  • • Dá resposta imediata antes do envio
Como validar:
  • • input → a cada caractere
  • • submit → antes do envio
  • • classList.add → adicionar estado
  • • .trim() → remover espaços
  • • .includes() → verificar conteúdo

✅ "Validar em tempo real é uma forma de respeito com quem está do outro lado."
