# 🚀 Martine Coding · Rise Up 2026

Repositório oficial da **Martine Coding** para as aulas e desafios implementados no **Rise Up 2026**, em parceria com o **Porto Digital**, no programa de residência tecnológica.
---

## 📌 Sobre o Programa

O **Rise Up 2026** é um programa de residência tecnológica realizado pelo **Porto Digital** em parceria com a **Martine Coding**, com o objetivo de formar novos talentos em **desenvolvimento frontend** e **marketing digital** para o ecossistema de tecnologia de Recife.

A formação combina duas trilhas complementares:

- 💻 **Desenvolvimento Frontend** — HTML, CSS, JavaScript, Git e frameworks modernos (React ou Angular)
- 📊 **Marketing Digital** — Branding, posicionamento, copywriting e growth hacking
---

## 🎯 Objetivo do Repositório

Centralizar todo o **material didático**, **exemplos práticos**, **desafios semanais** e **projetos finais** desenvolvidos durante a formação.

Este repositório serve como:

- 📚 **Material de apoio** para os alunos durante as aulas
- 🧪 **Ambiente de experimentação** para os exercícios práticos
- 📁 **Portfólio de referência** para o projeto final
- 🔗 **Ponte de contato** entre alunos, instrutoras e o ecossistema

## 🧠 O que os Alunos Vão Aprender

### Módulo 1 — Fundação (HTML + CSS)
- Tags semânticas, hierarquia e navegação
- Cores, fontes, Box Model e Flexbox
- CSS Grid, responsividade (mobile-first) e pseudo-classes
- Formulários, tabelas e elementos interativos

### Módulo 2 — Interatividade (JavaScript)
- Variáveis, arrays, objetos e funções
- Manipulação do DOM e renderização dinâmica
- Eventos, validação de formulários e `preventDefault`
- localStorage e persistência de dados

### Módulo 3 — Ferramentas Modernas
- Git, GitHub, branches e Pull Requests
- NPM, Vite e estrutura de pastas moderna
- Dados mockados e hardcoded em projetos frontend

### Módulo 4 — Framework (React ou Angular)
- Componentes, props e data binding
- Estado (useState / Services)
- Rotas e navegação
- Estado global (Context API / Services)
